# 構成: AI活用 社内勉強会のご案内

- テーマ: D（クラフト・緑＋黄） / 用途: 社内向け資料 / スタイル: visual / viz: high / 全 7 枚
- 想定: 全社員への案内 ＋ 各部門長への承認依頼。投影前提

## スライド 1: 表紙
- 役割: 何の資料か / 誰宛か / いつ・誰が
- レイアウト: 型H ドット帯（上下にドット列、アクセント3段階の濃淡）
- なぜこの形か: 教材・社内共有向けで軽快。テーマDは全面ダーク0枚のため型C（ウォーターマーク）は選べず、型Hが内容に最も近い

## スライド 2: 結論
- 役割: 何をどうしたいかを1枚で言い切る（社内資料は結論が先）
- レイアウト: 焦点コピー（40px）＋ 事実チップ3つ（等幅・同色）
- なぜこの形か: 結論は図解ではなく言い切りが要る。付随する事実は等しい重さの並列なのでチップで足りる
- 黄マーカー①: 「業務時間内での参加」

## スライド 3: 業務でAIを使っているのは3割
- 役割: 結論を支える数字
- レイアウト: 横バー（31%）＋ 大タイポ ＋ 下段に理由の横バー（48%）
- なぜこの形か: 内容の性質が「比率」。第2候補の card grid（数字3つ）は比率が消えるので退けた
- 出典: 社内アンケート（2026年7月実施・回答412名）

## スライド 4: 全4回で「触る」から「組み込む」まで
- 役割: 全4回の中身と日程
- レイアウト: 縦 ladder（各行の左に段数が1つずつ増える積み上げインジケータ、行は罫線で区切る）
- なぜこの形か: 内容の力学が「積み上がる」。第2候補の横向き arrow chain（§8-H）は横流れになり上昇が消えるので退けた。テーマDの「箱で囲わず罫線で仕切る」に合わせて背景塗りは使わない

## スライド 5: 60分の使い方
- 役割: 1回の中身（参加判断の材料）
- レイアウト: §8-D 時間軸タイムラインバー（15:30:15＝25%:50%:25%）
- なぜこの形か: 幅が実時間比という材料由来の根拠を持つ。第2候補のジャーニー3-zone（§8-F）は時間比率が消えるので退けた
- 塗りは進行の濃淡（tint → accent → accent-deep）。バー内に文字は載せない

## スライド 6: 参加に必要なもの
- 役割: 参加のハードルを下げる ＋ 申込導線
- レイアウト: §8-B チケット（本体2×2 ＋ 右stub、境界に破線のミシン目）
- なぜこの形か: 内容の性質が「持ち物・チェックリスト」。第2候補の横並びチップは「持ち帰る/持ち込む」の意味が出ないので退けた

## スライド 7: 決めていただきたいこと
- 役割: 各部門長に何を・いつまでに判断してほしいか
- レイアウト: ダークブロック（承認事項）＋ 下に1行ストリップ（決裁者と期限）
- なぜこの形か: 社内資料で最も価値があるブロックなので、デッキ唯一のダーク面を割り当てて主役を明示する
- 黄マーカー②: 「8月28日（金）」
