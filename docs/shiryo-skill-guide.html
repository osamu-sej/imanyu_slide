どのスキルで資料を作るか

出力形式・宛先・段階の3つが決まれば、行き先は1つに決まる。迷ったときはこの順で辿る。

決定フロー

依頼の時点で形式が決まっているなら、フローを飛ばして直接そのスキルを名指しすればよい。決まっていないときだけ上から辿る。

迷いやすい二択

実際に迷うのはこの2つだけ。どちらも「好み」ではなく、外部条件で決まる。

.pptx か HTML か
.pptx が要る
  • 受け取った人が中身を編集する
  • 提出形式として指定されている
  • 既存のパワポに差し込む
  • 社内の正式フォーマットに乗せる
HTML で足りる
  • 見るだけ・投影するだけ
  • 形式の指定がない
  • 単体で完結してよい
  • PDFで配れば済む

提出形式の指定があるかを先に確認する。ここを外すと作り直しになり、いちばん高くつく。指定がないなら shiryo-slides を第一候補にしてよい — 生成後に自分でスクリーンショットを撮って直す工程があるぶん、はみ出しや整列崩れが残りにくい。

SEJテンプレか 汎用か
seven-eleven-pptx
  • SEJの名前で外に出る
  • 社内の正式な提出物
  • ブランドガイドライン準拠が要る
ppt-build-standard
  • 社外提案・他社との共同
  • 研修・勉強会の教材
  • 個人プロジェクト

宛先で決まる。作り手の好みではない。seven-eleven-pptx はIRレポート調の配色（青・グレー・淡い茶の3系統）と「白抜き文字を使わない」規約を持っているので、SEJの資料として並べたときに揃う。

10スキルの一覧

同じ .pptx を作るスキルが4つあるので、その違いは「出力」ではなく「入力と場面」で見る。

スキル出力使うとき効きどころ
スライドshiryo-slides HTML 1枚
16:9		 社内資料・提案資料。形式の指定がないとき 5テーマから選ぶ。生成後にPlaywrightで撮って自分で直す。既存スライドの修正・PDF化も担当
seven-eleven-pptx .pptx SEJの名前で出す資料 コーポレートテンプレ。IRレポート調の配色・白抜き文字なし
ppt-build-standard .pptx SEJブランドを載せない案件 構成設計の出力をそのまま入力に取る。Phase1〜6で完成まで通す
pptx-pro .pptx ゼロから凝ったデザインで作る アニメーション・タイポグラフィ・メディア配置に強い
pptx .pptx / .potx 既存ファイルを読む・直す・抽出する 入出力が .pptx そのもののとき。テンプレート適用・結合・分割・ノート操作
前段ppt-structure-design 設計図 構成・ストーリーだけ先に固めたい 目的／聴衆／キーメッセージ → ナラティブ → 各スライドの指針。材料が薄いときほど効く
文書docx .docx / .dotx Word文書・報告書・letterhead 目次・見出し・ページ番号。変更履歴やコメントの操作も
xlsx .xlsx / .csv 表・データ・数式・グラフ 崩れた表データの整形にも。成果物がスプレッドシートのときだけ
pdf .pdf 結合・分割・抽出・OCR・フォーム記入 既存PDFの操作が中心。新規PDFは docx や shiryo-slides から出すほうが速い
社内文書sej-internal-comms テキスト 週次報告・ニュースレター・FAQ・通達 OP情報チームの発信物。スライドではなく文面が成果物のとき

トリガーの衝突

seven-eleven-pptx の説明文には、こう書かれている。

Osamuさんからのプレゼン作成依頼には常にこのスキルを使用すること。

一方 shiryo-slides は「資料を作って」「スライドにして」で発火する。この2つは正面からぶつかっていて、依頼の言い方次第でどちらが動くかが揺れる。HTMLで欲しいときにパワポが出てくる、あるいはその逆が起きる。

01claude.ai のスキル設定を開く（~/.claude/skills/synced/ は同期される領域なので、手元で直しても次回の同期で消える）
02seven-eleven-pptx の説明文の末尾を、条件つきに書き換える
Osamuさんから SEJの名前で出す資料 の作成を依頼されたときは常にこのスキルを使用すること。
形式が指定されていない場合や、社外提案・研修・個人プロジェクトの場合は shiryo-slides / ppt-build-standard を検討する。

これで「常に」の範囲が宛先で切れるので、ルーターや shiryo-slides と競合しなくなる。

ルータースキル shiryo-router を入れてあるので、形式が決まっていないときは「資料作って」だけで選択肢が出る。
このページは手元のスキル構成を写したもの。スキルを増減したら更新すること。
